# Medusa — Remote Environment
This is a remote (CDE) environment for [Medusa (info + deploy)](https://app.zerops.io/recipes/medusa?environment=remote-cde) recipe on [Zerops](https://zerops.io).

<!-- #ZEROPS_EXTRACT_START:intro# -->
**Remote (CDE)** environment mirrors the agent topology — production `medusa` and `nextstore` plus hobby data services — so a developer can SSH into either Node container and iterate without installing Postgres, Valkey, Meilisearch, or MinIO locally.
